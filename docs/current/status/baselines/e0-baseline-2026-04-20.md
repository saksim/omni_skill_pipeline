## 模态观察

### Text

- 优点：
  - step / rule / anti-pattern / verification 均可被抽出
  - evidence 数量与 skill 结构基本匹配
- 病灶：
  - summary 仍机械
  - title 行进入 summary 的现象仍存在

### Audio

- 优点：
  - transcript-only 路径稳定
  - procedure / rule / anti-pattern / verification 能形成基本闭环
- 病灶：
  - 仍缺 speaker role 与 utterance act
  - 无法表达 unresolved question / decision lineage

### Tabular / Time-Series

- 优点：
  - evidence 最丰富，且已有 `TABLE / METRIC / EVENT` typed evidence 雏形
  - analysis 类型已被正确识别
- 病灶：
  - publication 层仍把 schema 行混入 step
  - step 与 guardrail 没有彻底分离
  - 说明当前需要 `SemanticAtom -> SkillGraph` 而不是直接 compose 文档

### Image

- 优点：
  - CLI 能跑通
- 病灶：
  - 只得到 1 条 evidence 与 1 条 insight
  - OCR 文本严重污染，最终 skill 基本失真
  - 说明当前缺 `layout / region / UI semantic` 层

### Video

- 优点：
  - CLI 能跑通
- 病灶：
  - 只得到 1 条 evidence 与 1 条 insight
  - 最终 skill 几乎退化为乱码 OCR
  - 说明当前缺 `scene cluster / subtitle alignment / frame event / timeline` 层

## E0 结论

- `text` 与 `audio` 可作为第一批 V2 对照基线。
- `tabular/time-series` 是当前最接近 V2 的链路，但 publication 层仍然错位。
- `image` 与 `video` 当前已经具备“必须优先重构”的充分证据。
- E1 开工前，E0 已满足“样本、产物、指标、测试”四件套要求。
