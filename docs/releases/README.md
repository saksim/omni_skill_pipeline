# Release Docs

Releases is the release layer: what shipped, what decision was made, and which standard governed the release.

Use this layer for:

- Changelog entries and release notes.
- Human-readable GitHub Release notes in [notes/](notes/README.md).
- Release switch standards and gate definitions.
- Dated release decision snapshots.

Long-lived manuals should live in `docs/latest/`; superseded historical context should move to `docs/archive/`.
