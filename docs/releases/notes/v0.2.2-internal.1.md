## What Changed

This internal release closes the non-infrastructure dogfood launch loop for the
API/CLI/review-queue path.

- Fixed the internal dogfood API smoke payload so it uses the current API schema
  contract for `DistillGoal.audience`.
- Added JSON and Markdown evidence output to `scripts/internal_dogfood_smoke.py`.
- Added real HTTP dogfood smoke evidence for `/healthz`, template retrieval,
  text distillation, and pending review queue visibility.
- Made FastAPI OpenAPI metadata read the package version instead of a stale
  hard-coded value.
- Refreshed broad launch readiness and internal dogfood readiness evidence.

## Why This Matters

`v0.2.1-internal.1` made the release wheel installable. The next launch blocker
outside Docker/Postgres/K8s was the live internal API smoke path: the smoke script
was not itself conforming to the API schema, and its output was not durable
enough for launch records.

This release makes the internal dogfood API path runnable and auditable without
claiming external Beta or GA readiness.

## How To Use It

Run the internal dogfood API smoke against a local API:

```bash
python scripts/internal_dogfood_smoke.py \
  --base-url http://127.0.0.1:8000 \
  --output docs/working/status/baselines/internal-dogfood-api-smoke-report.json \
  --summary-output docs/working/status/baselines/internal-dogfood-api-smoke-summary.md
```

Verify the release wheel as a consumer:

```bash
python scripts/release_consumer_smoke.py --release-dir . --expected-release-id v0.2.2-internal.1
```

## Release Boundary

This is an internal dogfood launch release. It excludes Docker, Postgres, K8s,
OCR hardening, encryption hardening, and external real-loop collection. The
external launch gate remains `HOLD` until real launch-gate-eligible loops meet
the documented threshold.
