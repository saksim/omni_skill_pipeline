# v0.2.5-internal.1 发布说明

## 本次变化

本内部版本在没有真实业务数据的前提下，把上线口径收敛为内部 dogfood，并把后续真实数据接入、验收和归档方式补齐为中文可执行手册。

相比 `v0.2.4-internal.1`，本版本新增和更新了以下内容：

- 新增 [真实数据接入与验收手册](../../latest/operations/runbooks/real-data-intake-and-validation.md)，明确真实原始数据放在 `data/real-inputs/<batch-id>/`，仓库只提交脱敏 manifest。
- 将 10 个 GL-63 真实闭环槽位、4 个目标模态、单槽位单 loop、source trace、review trace、agent smoke 记录写成操作者可执行规则。
- 明确当前没有真实数据时只能发布为内部 dogfood 或内部玩具，不声明外部 Beta、GA、SaaS 或生产可用。
- 将 GL-64 预检与 GL-13 强制摄入门禁的操作口径写入当前文档入口和 P0 施工文档。
- 新增内部 dogfood 与真实数据接入预案归档，记录本轮没有伪造真实数据，只准备后续真实数据接入路径。
- 将 package metadata 版本更新到 `0.2.5`，并将 release note、changelog、索引和当前操作入口更新到 `v0.2.5-internal.1`。

## 为什么重要

前一个版本已经完成中文文档和发布记录整理，但真实业务数据仍不存在。继续强行追求外部上线会制造虚假信号。

本版本选择更严格的做法：当前只发内部 dogfood，同时把未来真实数据到来后的接入路径准备好。这样项目现在可以继续内部验证，未来拿到真实数据时也不需要重新讨论目录、格式和验收标准。

## 发布边界

本版本仍不是外部 Beta、GA、SaaS 或生产部署声明。

仍不属于本版本完成范围：

- 真实业务闭环数据达标。
- 外部 Beta readiness。
- GA/SaaS readiness。
- Docker real-run closure。
- Postgres 生产验证。
- K8s/Kubernetes 操作。
- Vault/KMS 集成。
