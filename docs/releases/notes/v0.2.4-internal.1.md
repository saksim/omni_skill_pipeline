## 本次变化

本内部发版候选把当前中文文档刷新纳入 release 记录，并补齐文档分层核验与归档证据。

- 将 README、`docs/INDEX.md`、`docs/latest/` 操作入口、runbook、环境变量、测试说明、发布入口和归档入口对齐到中文工程师可直接执行的表述。
- 新增本 release note，让 GitHub Release 产物能说明本版到底发了什么。
- 新增 `docs/archive/status/2026-06-20-documentation-localization-archive.md`，归档文档分层核验结论。
- 更新 `docs/releases/CHANGELOG.md`、`docs/releases/notes/README.md` 和主索引，让 `v0.2.4-internal.1` 可被发现。
- 将 package metadata 版本更新为 `0.2.4`，用于下一次内部 release package。

## 为什么重要

`v0.2.3-internal.1` 已经完成本地 file-backed artifact 加密加固，但发布页和操作文档没有充分说明本轮文档中文化、归档和操作入口整理的成果。

本版不把历史复杂性继续压到施工文档里，而是把“现在用什么、这次发了什么、过去发生过什么”分层固定下来：

- `docs/latest/`：当前应该使用的操作手册。
- `docs/releases/`：本次 release 说明、changelog 和发布决策。
- `docs/archive/`：已经完成或已经替代的历史事实。
- `docs/working/`：仍在迭代的计划、证据和施工状态。

## 发布边界

本 release 是文档与发布记录补齐，不新增运行时能力声明。

仍不属于本版完成范围：

- 外部 Beta readiness。
- GA/SaaS readiness。
- 真实 launch-gate-eligible 业务闭环数量达标。
- OCR hardening。
- Docker real-run closure。
- Postgres 生产验证。
- K8s/Kubernetes 操作。
- Vault/KMS 集成。
- 自动 key rotation。
