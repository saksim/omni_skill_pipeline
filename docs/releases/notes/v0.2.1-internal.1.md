## 本次变化

本内部 release 修复 `v0.2.0-internal.1` 发布后发现的第一个真实 consumer smoke 失败。

- 将 `SKILL.template.md` 和 `skill.schema.json` 打包进 Python wheel。
- 更新 runtime settings，使 installed wheel 在非源码仓运行时可以回退到 packaged contracts。
- 增加 release consumer smoke script，验证 checksums、manifest contract、wheel 安装，以及 installed wheel 的 `show-template`。
- 在 artifact upload 和 GitHub Release publication 前，把 consumer smoke 接入 `Release` workflow。
- 增加 packaged contract resources 和 release consumer smoke failure modes 测试。

## 为什么重要

`v0.2.0-internal.1` 证明 GitHub Release publication 可用，但 consumer install 暴露了一个缺口：wheel 期望 installed package 旁边存在仓库 docs。对普通下载 release 的用户来说，这个假设不成立。

本 release 关闭该缺口。用户可以在仓库外安装 wheel，并正常运行 template CLI smoke。

## 如何使用

安装本 release 的 wheel，然后验证 CLI 入口：

```bash
python -m pip install omni_skill_pipeline-0.2.1-py3-none-any.whl
python -m omni_skill_pipeline.cli show-template
```

验证下载文件：

```bash
sha256sum -c SHA256SUMS
```

对下载产物执行 release consumer smoke：

```bash
python scripts/release_consumer_smoke.py --release-dir . --expected-release-id v0.2.1-internal.1
```

## 发布边界

本 release 改进 packaged artifact 和 post-release verification 层。它仍不单独声明完整生产运行时部署。Docker、Postgres、external beta 和真实 launch-gate 证据仍是独立门禁。
