# Working 文档

`docs/working/` 是当前迭代层，用于保存仍在推进中的计划、状态、backlog、施工单、baseline 和运行证据。

适合放在本层的内容：

- 当前状态、上线 readiness 判断和未完成 blocker。
- 路线图、backlog、work order 和施工计划。
- baseline、trial manifest、报告和迭代中生成的证据。
- 内部 dogfood 上线计划、门禁、失败修复记录。
- GPT5.5 或后续工程师继续施工所需的阶段性蓝图。
