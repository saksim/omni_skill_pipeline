# Working Docs

Working is the current iteration layer: active plans, status, backlog, and generated evidence.

Use this layer for:

- Current status and launch-readiness notes.
- Roadmaps, backlogs, work orders, and open iteration plans.
- Baselines, trial manifests, reports, and evidence generated while work is in progress.

Material graduates from here into `docs/latest/` when it becomes the published manual, or into `docs/releases/` when it records a release decision.
