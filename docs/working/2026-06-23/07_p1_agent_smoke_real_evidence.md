# P1：Agent Smoke 真实运行证据规范

## 1. 背景

当前项目已有 agent smoke 协议和矩阵验证。评估中运行：

```bash
python scripts/agent_smoke.py --validate-matrix --fail-on-incomplete --print-json
```

可以得到矩阵完整的结果，但记录中存在：

```text
passed_record_count=1
not_run_record_count=2
failed_record_count=0
```

这说明当前更接近“记录矩阵完整”，不是“三类 Agent 全部真实运行通过”。

## 2. 核心判断

对于 internal dogfood，`not_run + documented reason` 可以解释；对于 external beta，`not_run` 不能作为 readiness 证据。

## 3. 目标

把 agent smoke 从“协议存在”升级为“真实运行证据”。最低需要覆盖：

| Agent | 是否需要真实运行 | 说明 |
|---|---:|---|
| Claude Code | 是 | 项目已经引用 CLAUDE 评价，应补真实 smoke |
| Codex | 是 | 面向代码/技能包消费的重要 Agent |
| OpenCode 或其他开源 Agent | 是 | 验证非单一厂商兼容性 |

如果某个 Agent 当前不可用，必须清楚标记为 Beta blocker 或非 blocker，不能混入 pass。

## 4. Agent smoke 必备内容

每条 agent smoke evidence 必须包含：

| 字段 | 必填 | 说明 |
|---|---:|---|
| `agent_name` | 是 | Agent 名称 |
| `agent_version` | 是 | 版本 |
| `runtime_env` | 是 | OS/Python/CLI/容器环境 |
| `skill_package_ref` | 是 | 使用的技能包路径/hash |
| `input_task` | 是 | 给 Agent 的任务 |
| `expected_behavior` | 是 | 期望 Agent 如何使用技能 |
| `execution_transcript_ref` | 是 | 脱敏运行记录 |
| `result_status` | 是 | passed/failed/not_run |
| `failure_reason` | 条件必填 | failed/not_run 时必须有 |
| `human_reviewer` | 是 | 人工判断人 |
| `review_decision` | 是 | approved/rejected |
| `created_at` | 是 | 时间 |

## 5. Agent smoke schema

```json
{
  "agent_name": "codex",
  "agent_version": "x.y.z",
  "runtime_env": {
    "os": "linux",
    "python": "3.11.x",
    "omni_skill_pipeline": "0.2.6-internal.3"
  },
  "skill_package_ref": "release/skills/portable/RL-001/agent_skill_package.json",
  "skill_package_sha256": "...",
  "input_task": "Use the provided skill package to perform the documented workflow on a redacted sample.",
  "expected_behavior": [
    "Agent reads SKILL.md",
    "Agent follows the ordered procedure",
    "Agent cites or references relevant skill constraints",
    "Agent produces an output matching business expectation"
  ],
  "execution_transcript_ref": "docs/working/status/agent-smoke/RL-001-codex.transcript.redacted.md",
  "result_status": "passed",
  "failure_reason": null,
  "human_reviewer": "redacted-reviewer",
  "review_decision": "approved",
  "created_at": "2026-06-23T00:00:00Z"
}
```

## 6. Smoke 测试任务模板

```markdown
You are given a portable skill package generated by omni_skill_pipeline.

Task:
1. Read the package metadata and SKILL.md.
2. Explain what the skill is for.
3. Apply the skill to the provided redacted mini-case.
4. Produce the expected output format.
5. Identify any missing or ambiguous instruction in the skill.

Pass criteria:
- The agent uses the skill rather than ignoring it.
- The output follows the skill's procedure.
- The agent does not hallucinate unavailable source details.
- The agent flags ambiguity instead of inventing sensitive details.
```

## 7. 真实 loop 关联规则

每条真实 loop 至少关联一个 Agent smoke。建议：

| Loop | 必需 Agent smoke |
|---|---|
| RL-001 | Codex |
| RL-002 | Claude Code |
| RL-003 | OpenCode |
| RL-004 | Codex |
| RL-005 | Claude Code |
| RL-006 | OpenCode |
| RL-007 | Codex |
| RL-008 | Claude Code |
| RL-009 | OpenCode |
| RL-010 | 任一 + 复核 |

更理想状态是每条 loop 三个 Agent 都跑一次，但这可作为 P2 增强。

## 8. 失败分类

| 状态 | 是否可接受为 Beta 证据 | 说明 |
|---|---:|---|
| `passed` | 是 | 有 transcript + 人审 approved |
| `failed` | 否 | 必须记录失败原因 |
| `not_run_env_unavailable` | 否 | internal 可以解释，Beta 不可用 |
| `not_run_agent_unavailable` | 否 | 不能算覆盖 |
| `passed_with_minor_issues` | 条件可接受 | 必须有人审批准 |

## 9. 脚本增强建议

`scripts/agent_smoke.py` 应支持：

```bash
python scripts/agent_smoke.py --require-real-runs --min-passed-agents 3 --print-json
```

并输出：

```json
{
  "agents_required": 3,
  "agents_passed": 3,
  "not_run": 0,
  "failed": 0,
  "status": "AGENT_SMOKE_REAL_EVIDENCE_READY"
}
```

## 10. 验收命令

```bash
python scripts/agent_smoke.py --validate-matrix --fail-on-incomplete --print-json
python scripts/agent_smoke.py --require-real-runs --min-passed-agents 3 --print-json
python scripts/launch_gate.py --print-json
```

期望：

```text
passed_record_count>=3
not_run_record_count=0 for beta-required agents
failed_record_count=0
```

## 11. 完成定义

1. 至少 3 类 Agent 有真实运行记录。
2. 每条记录有版本、环境、技能包 hash、任务、transcript、人审结论。
3. `not_run` 不再被用于 Beta readiness。
4. 真实 loop manifest 能引用 agent smoke evidence。
5. launch gate 能识别 agent smoke 缺失。

## 12. 禁止的伪修复

不允许：

- 把 `not_run` 改名成 `passed`；
- 只写人工说明，没有执行 transcript；
- 只证明 Agent 能启动，不证明它使用技能包；
- 只跑一个 Agent，却宣称多 Agent 支持；
- 用 mock Agent 充当真实 Agent；
- 删除 `fail-on-incomplete` 逻辑。
