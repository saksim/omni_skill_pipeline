# Controlled Trial Fixtures (CBT-10)

This directory contains tiny sanitized fixtures for offline controlled-trial validation.

## Coverage
- `text/`: markdown + tiny PDF placeholder
- `audio/`: audio stub + transcript sidecar
- `image/`: dashboard screenshot stubs
- `video/`: video stub + subtitle sidecar
- `tabular/`: latency/error CSV
- `mixed/`: mini incident bundle

## Notes
- Fixtures are intentionally small and non-sensitive.
- Video/audio binaries are stubs for offline tests; semantic content is driven by sidecars.
